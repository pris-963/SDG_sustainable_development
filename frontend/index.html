Model

Prediction methodology

Algorithm

Linear Regression is used to model the historical relationship between year and maternal mortality ratio.

Input

Historical MMR values from SDG indicator 3.1.1 are used as the primary input for prediction.

Output

The model estimates future MMR values and provides a 2030 forecast that can be compared with the SDG target of 70.

Evaluation

Mean Absolute Error, Root Mean Squared Error and R² can be used to evaluate the regression model.

Indicator

SDG 3.1.1 — Maternal Mortality Ratio (MMR), measured per 100,000 live births.

Dataset

Sustainable Development Goals National Indicator Framework dataset containing Indian area-level observations.
